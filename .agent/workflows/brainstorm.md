---
description: Workflow para brainstorm de melhorias e novas features
---

1. Ler `SLX_PROJECT_MEMORY.md` para entender a visão do projeto.
2. Pesquisar tendências web atuais para jogos HTML5 e monetização (AdSense).
3. Propor 3 melhorias concretas focadas em:
   - Retenção de usuário (Gamification).
   - Estética (UI/UX Premium).
   - Monetização (Otimização de Ads sem prejudicar UX).
4. Criar um artefato `feature_ideas.md` com as propostas.
5. Perguntar ao usuário qual delas ele gostaria de planejar para implementação.
